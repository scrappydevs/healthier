## Web Dashboard Features

### Medication Logging and Procedures
- Scan medications to generate clear instructions + interact with a voice agent that will guide you through yuor daily routine
- Clinician has ability to assign medications and receives progress insights 

![2D Map (1)](https://github.com/user-attachments/assets/f999f80d-e0c8-456b-a2c4-95c8f0f4540d)

### Meal Assignment and Tracking
- Assign patients specific meals and caloric goals
- Analyze approximate nutrition signals (e.g. protein, vitamins, general healthiness)

<img width="1728" height="991" alt="dash" src="https://github.com/user-attachments/assets/edb3602f-6057-4ab3-9909-8cdef1eaa485" />


### Exercise Tracking & Analysis
- Live video analysis
- Checks form + provides feedback using CV pipelines
